# مدلت (Modelet)
سایت بازار آنلاین پوشاک. فایل `index.html` نسخهٔ نهایی و کاملاً مستقل است؛ مستقیم در مرورگر یا هر هاست ایستا باز می‌شود.

- `src/` فایل‌های منبع و اسکریپت `merge.py` که `index.html` را می‌سازد (مسیرهای داخل merge.py مربوط به محیط ساخت است و باید تنظیم شود).
- `assets/models/` تصاویر مدل‌ها برای «تازه‌های مدلت».
- `backend/` دیتابیس کاربران و ارسال پیامک کد ۴ رقمی (Supabase)؛ راه‌اندازی در `backend/README.md`. بدون آن، ورود در حالت نمایشی است.

کلیدها و رمزها را هرگز در مخزن نگذارید.
